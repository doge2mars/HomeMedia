设置按组折叠：点组名展开，默认只开视频源，其他组收着，不再一屏拉到底。

首页板块显示（可开关）
勾上的板块才在首页出现，改完点保存，下次进首页生效。“热门电影 / 热门剧集”是豆瓣榜单（豆瓣挂了自动回退到目录库最新入库）；“家人在看”是全家最近 7 天看过且完成度高的片，空时自动回退到华语口碑剧集榜；“即将上映”在这里勾选开关，数据源（慢看/TMDB/关闭）在下面“即将上映数据源”那组里选，数据源关掉则首页也不显示该板块。“源站热门”是各源周点击量最高的片，只作参考（点击量水分大）；“TMDB 本周趋势”需在下面“即将上映数据源”那组填了 TMDB key 才出现，没填就不显示。
视频源（苹果 CMS）
单个添加：key + 名称 + api 地址（形如 https://xxx/api.php/provide/vod/）。电视端的搜索资源列表就是从这里来的，改完电视端不用改 APK。源管理仅站长（owner）可改，普通用户只能看、只能用。
订阅导入（配置订阅）
订阅地址可以是公开源列表，也可以是你放在 NAS/电视盒上的局域网地址；导入时按归一化 api 去重，已有相同 api 的源只更新名称、不重复建。导入后地址会保留在下面列表里，可手动更新、删除；更新会替换该订阅带来的源；目录定时同步时也会顺带刷新订阅。
目录同步（货架）
勾上的源是主源：同步时只拉这些源、每类拉下面填的页数；没勾的源是备用：不进货架，但实时搜索、点播照常用。同步是后台跑的，跑的时候旧货架照常用，跑完货架就变厚了。定时点模式：下面填了时间（北京时间），就每天这个点拉一次、顺带把上映数据也刷了，间隔那项就不起作用；不填时间就按间隔拉。
每类拉 页 每 小时 填了就每天这个点拉（比如半夜 03:00），不填按间隔拉
全不选 = 不拉任何源，货架不再更新（不建议）。
图片代理（服务端拉图）
海报是服务端去源站拉的：先直连，15 秒超时或失败后，按下面列表顺序走代理重试，成功才进缓存。直连快的国内图床不受影响，只有拉不到的图才走代理。一行一个，形如 http://192.168.123.1:7890；留空 = 只直连。仅站长可改。
豆瓣代理（首页榜单）
首页“热门电影 / 热门剧集”走豆瓣榜单（tag=热门，sort=recommend），服务端去豆瓣拉，24 小时缓存。豆瓣有反爬，直连被拦就换个代理：腾讯/阿里是社区搭的豆瓣 CDN 镜像（LunaTV 同款），Zwei 是 CORS 代理，自定义填自己的镜像域名。改完立即生效（榜单缓存会清空）。仅站长可改。
直播源
单个添加：M3U 地址；订阅导入：M3U、TVBox TXT（分组,#genre# / 频道,地址）、TVBox JSON（lives 数组）、直播导入 JSON（sources 数组）都会自动识别。家里电视盒里的直播源，不管是 M3U 文件地址还是 TXT/JSON 订阅地址，贴进来就行。

账户管理
站长（owner）可加人、删人；每人自己的播放记录、收藏、设置都是隔离的，换设备登录就跟过去，不用重新配。

播放设置（跟人走，服务端存）
存在服务端、按账号存，电视、网页、手机登录同一个账号就用同一套，不用每台设备重配。倍速、跳过片头片尾是预留项，播放器下一步接。
默认倍速
服务端缓存
搜索结果缓存 10 分钟、详情 30 分钟、直播频道 6 小时、分类 24 小时、海报 7 天。缓存是给“不常变的数据”准备的：新剧上架、集数更新，搜索/详情在缓存期内会晚一点看到，点“刷新”或“清空缓存”就实时拉。m3u8 播放列表本身不缓存，播的时候永远实时取，断点和收藏存在数据库里，不走缓存。
清空后下一次搜索/开直播会慢一次，随后重新缓存。
即将上映数据源
默认慢看（抓慢看网电影/电视剧时间表，国内站直连，不用 key，数据是过去 7 天到未来 90 天）。TMDB 是官方接口、需填免费 key，海外站走代理更稳，只给电影。关掉则首页不显示即将上映板块。上映数据一天缓存一次，点“立即刷新”可手动刷。

图片代理
全部海报走服务端 /api/image-proxy + 磁盘缓存 + 目录同步后预取。电视端源站海报因 APK 只改写豆瓣/Bangumi 图，仍直连——电视海报想快，把图床域名加进你那边的 DirectMedia 直连规则。
